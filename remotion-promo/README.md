# Cadence Remotion promo

Lives in **cadence-front-door** beside the interactive `/product` demos.

**Dual path (locked):** interactive cascade on `/product` **and** this Remotion package for social/ads MP4. Same locked copy and settle tempo; different delivery.

## Compositions

| ID | Purpose |
|----|---------|
| `CadencePromo` | ~22s spine: open → map rest → cascade settle → rest line → ask |
| `CascadeCaptureEval` | Looping settle for judging Remotion vs CSS/live capture |

## Commands

```bash
cd remotion-promo
npm i
npm run dev
npx remotion render CadencePromo out/cadence-promo.mp4
```

From the front-door root:

```bash
npm run promo:dev
npm run promo:render
```
